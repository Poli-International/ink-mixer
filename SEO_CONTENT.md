## What is Pigment Ink Mixer?

The Pigment Ink Mixer is a free web-based color mixing calculator designed specifically for professional tattoo artists. It calculates precise pigment ratios and volumes needed to create custom ink colors. The tool features five main sections: a color mixer calculator, a formula library, a skin tone mixing guide, a gray wash calculator, and a color theory reference.

The core functionality allows artists to select up to 10 colors from a database of 12 predefined pigments (black, white, red, yellow, blue, orange, green, purple, brown, magenta), assign parts to each color, and specify a total volume. The tool then calculates exact measurements in parts, milliliters, drops, and percentage for each color in the mixture. It also generates a visual color preview based on RGB estimation.

Built with HTML, CSS, and JavaScript, the tool stores formulas locally in the browser using localStorage, allowing artists to save, search, import, and export their custom recipes. The tool includes a comprehensive database of professional formula presets organized by category: skin tones, portrait details, grays/neutrals, and landscape colors.

## How to Use

### Step 1: Select Colors to Mix

1. Navigate to the **Color Mixer** tab (default active tab).
2. For **Color 1**, click the dropdown and select a pigment from the list:
   - **Primary Colors:** Black, White, Red, Yellow, Blue
   - **Secondary Colors:** Orange, Green, Purple
   - **Earth Tones:** Brown
   - **Specialty:** Magenta
3. Set the **Parts** value for Color 1 (minimum 0.1, increments of 0.1).
4. For **Color 2**, repeat the selection and parts process.
5. To add more colors, click the **+ Add Another Color** button (up to 10 colors).

### Step 2: Set Total Volume

1. Enter the **Total Volume Needed** in the number input field.
2. Select the unit:
   - **ml** (milliliters)
   - **caps** (1 cap ≈ 2ml)

### Step 3: Calculate Your Formula

1. Click the **🧪 Calculate Mixture** button.
2. Review the results section:
   - **Color Preview:** Approximate visual representation of the mixed color.
   - **Ratio Formula:** The simplified ratio of all colors (e.g., 10:3:1:0.25).
   - **Measurements Table:** Detailed breakdown showing for each color:
     - Parts
     - Volume (ml)
     - Drops
     - Percentage of total mix

### Step 4: Save Your Formula

1. In the **Save This Formula** section, enter a **Formula Name** (e.g., "Light Caucasian Skin").
2. Add optional **Notes** (e.g., "Works well for portraits, adjust red for warmth").
3. Add optional **Tags** (comma-separated, e.g., "portrait, skin, realism").
4. Click **💾 Save Formula** to store it in your browser's local storage.
5. Access saved formulas in the **My Formulas** tab.

### Using the Skin Tone Mixer

1. Switch to the **Skin Tones** tab.
2. Select a **Skin Tone Category** from 10 options (Light Caucasian through Deep Brown/Black).
3. Choose an **Undertone** (Neutral, Warm, Cool).
4. Set the **Volume Needed** in ml.
5. Click **🎨 Generate Skin Tone Formulas**.
6. Review the generated base, highlight, and shadow formulas.

### Using the Gray Wash Calculator

1. Switch to the **Gray Wash** tab.
2. Use the slider to set **Gray Value (% Black)** from 5% to 90%.
3. Enter **Total Volume** in ml.
4. Optionally check **Include Witch Hazel (30% of diluent)**.
5. Click **🌫️ Calculate Gray Wash**.
6. Review the black ink and water/witch hazel measurements.
7. Use the **Quick Gray Shade Ladder** to click any shade (10%-80%) and auto-calculate.

## Frequently Asked Questions (FAQ)

### Q1: How many colors can I mix at once?
You can mix up to 10 colors simultaneously. The tool starts with 2 color rows and you can add more using the "+ Add Another Color" button.

### Q2: Can I save my custom formulas?
Yes. After calculating a mixture, enter a formula name, optional notes, and tags, then click "Save Formula." Formulas are stored in your browser's local storage and accessible from the "My Formulas" tab.

### Q3: How accurate is the color preview?
The color preview is an approximate RGB estimation based on the ink color database values. Actual results vary based on ink brands, skin type, and application technique. Always test colors on practice skin before use.

### Q4: Can I export my formulas to another device?
Yes. In the "My Formulas" tab, click the "Export" button to download all saved formulas as a JSON file. You can then import this file on another device using the "Import" button.

### Q5: What is the difference between "ml" and "caps" for volume?
"ml" is milliliters, a standard metric volume measurement. "caps" refers to tattoo ink cup caps, where 1 cap is approximately 2ml. This helps artists measure using common studio supplies.

### Q6: How do I calculate a gray wash?
Go to the "Gray Wash" tab, use the slider to select your desired gray percentage (5%-90% black), enter the total volume, optionally check "Include Witch Hazel," and click "Calculate Gray Wash."

### Q7: What skin tones are available in the Skin Tone Mixer?
The tool includes 10 skin tone categories: Light Caucasian, Medium Caucasian, Olive/Mediterranean, East Asian, South Asian/Indian, Hispanic/Latino, Light Brown, Medium Brown, Dark Brown, and Deep Brown/Black.

### Q8: Can I search my saved formulas?
Yes. In the "My Formulas" tab, use the search bar to filter formulas by name, notes, or tags.

### Q9: Is this tool free to use?
Yes. The Pigment Ink Mixer is completely free with no attribution required. It is provided as a professional tool by Poli International.

### Q10: Does the tool work on mobile devices?
Yes. The tool is mobile responsive and touch-optimized for use on smartphones and tablets.
